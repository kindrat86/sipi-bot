Agent spend policy patterns — daily ceiling, allowlist, per-tx, velocity

These policy pages describe the four rule patterns that cover almost every agent-spend scenario. Each one shows the rule shape, the failure mode it prevents, and how to combine it with the others into a complete spend firewall.

Spend policy patterns

  • Daily spend ceiling policy | sipi.bot

    A daily ceiling policy caps total agent spend in a 24-hour window. This guide covers how to set ceilings that balance safety with the agent&#x27;s task scope.

  • Merchant allowlist policy | sipi.bot

    A merchant allowlist policy restricts which merchants an agent can transact with. This guide covers allowlist design patterns for different agent use cases

  • Per-transaction limit policy | sipi.bot

    A per-transaction limit policy caps the dollar value of any single spend an AI agent can execute. This guide covers recommended limits by use case and how

  • Velocity cap policy | sipi.bot

    A velocity cap policy limits the number of transactions per minute an agent can execute. This guide covers recommended velocity caps by agent type.
